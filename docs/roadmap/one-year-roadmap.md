# One-Year Roadmap

This roadmap assumes the project starts in June 2026 and has at least one year for research, implementation, evaluation, and thesis writing.

## Phase 1: Project Definition and Research

Time: Month 1 to Month 2

Goals:

- Finalize project title and scope.
- Collect official source candidates.
- Define local Vietnamese entrepreneur and foreign investor user journeys.
- Draft thesis outline.
- Confirm technology stack.

Deliverables:

- Project brief.
- Literature review notes.
- Initial source list.
- Requirement draft.
- Architecture draft.

## Phase 2: Domain Model and Knowledge Base Design

Time: Month 3 to Month 4

Goals:

- Model business scenarios and procedures.
- Design knowledge base schema.
- Define review workflow.
- Build first source ingestion process.
- Create first manually verified checklist set.

Deliverables:

- Knowledge base schema.
- First approved source snapshots.
- Scenario checklist templates.
- Admin workflow design.

## Phase 3: MVP Website and Backend

Time: Month 5 to Month 6

Goals:

- Build frontend prototype.
- Build backend API.
- Implement chatbot endpoint.
- Implement guided questionnaire.
- Implement checklist display.

Deliverables:

- Working local web app.
- API documentation.
- Basic chatbot with approved knowledge retrieval.
- Demo scenario for one user journey.

## Phase 4: Blockchain Registry and Verification

Time: Month 7 to Month 8

Goals:

- Implement smart contract.
- Register approved knowledge versions.
- Add verification page.
- Connect backend to blockchain.
- Test tamper detection.
- Select a low-cost EVM-compatible deployment target for demo.

Deliverables:

- `KnowledgeRegistry` smart contract.
- Smart contract tests.
- Backend blockchain integration.
- User-facing verification view.
- Low-cost EVM deployment notes.

## Phase 5: AI Quality and Admin Review

Time: Month 9

Goals:

- Improve RAG retrieval.
- Add citation quality checks.
- Add refusal behavior for unsupported answers.
- Build admin/reviewer UI.
- Add more business scenarios.

Deliverables:

- Improved chatbot.
- Admin dashboard.
- Reviewed knowledge version workflow.
- Evaluation question set.

## Phase 6: Evaluation

Time: Month 10

Goals:

- Run chatbot accuracy tests.
- Run usability testing.
- Run blockchain verification tests.
- Analyze results.

Deliverables:

- Test reports.
- User feedback summary.
- Accuracy and trust metrics.
- Limitations analysis.

## Phase 7: Thesis Writing and Final Polish

Time: Month 11 to Month 12

Goals:

- Complete thesis chapters.
- Finalize documentation.
- Prepare demo video and slides.
- Clean code and deployment scripts.
- Prepare defense presentation.

Deliverables:

- Final thesis report.
- Final demo.
- Final source code.
- Presentation slides.
- Deployment guide.

## Buffer / Extension Ideas

If time remains:

- Improve Vietnamese and English bilingual support.
- Add automatic source monitoring.
- Add expert marketplace handoff.
- Add mobile-responsive improvements.
- Add more Da Nang-specific investment scenarios.
- Compare EVM deployment options and briefly discuss permissioned blockchain as future work.
